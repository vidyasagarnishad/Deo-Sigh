# Deosingh Bishakarma — Portfolio

Fresh static portfolio implementation.

## Files
- index.html — semantic page structure/content
- style.css — responsive visual system
- script.js — GSAP + ScrollTrigger interactions
- README.md — setup notes

## Run locally
Do not open `index.html` directly with file:// if you want to test every browser behavior consistently.

Recommended:
1. Open this folder in VS Code.
2. Install/use Live Server, or run another simple local HTTP server.
3. Open the resulting http://localhost URL.

The site uses Google Fonts and GSAP from CDN, so internet access is required for those assets.

## Content policy
The site content is based on the supplied resume. The "Selected Work" section describes industry/application work supported by the resume rather than inventing case studies or visual deliverables.

## Deployment
The folder can be deployed directly to Vercel, Netlify, GitHub Pages, or any static hosting provider.
